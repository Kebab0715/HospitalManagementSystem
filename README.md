# Hospital Management System

A console-based Hospital Management System built with Java, demonstrating core Object-Oriented Programming (OOP) principles.

## 📌 Features
* **Patient Management:** Add and list patient records with their specific ailments.
* **Doctor Directory:** View available doctors and their medical specialties.
* **Appointment Scheduling:** Book and manage appointments by matching patients with doctors.

## 💻 Tech Stack & Concepts
* **Language:** Java
* **Concepts:** Object-Oriented Programming (Classes, Objects, Encapsulation), Collections (ArrayList)

## 🚀 Future Enhancements
